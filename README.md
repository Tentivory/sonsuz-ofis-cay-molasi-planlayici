# Sonsuz Ofis Çay Molası Planlayıcı

## Resmi Açıklama

Bu proje, insanlık tarihinin en önemli bilimsel başarılarından biridir. Ofis çalışanlarının en büyük sorununu çözmektedir: **Çay molasının ne zaman biteceği**.

Cevap: Asla.

## Nasıl Çalışır?

```bash
python molasi_planla.py
```

Kod sonsuza kadar çalışır, resmi mesajlar basar ve sizi bekletir. Gerçekten. Çay içmez ama demleniyormuş gibi yapar. İdare eder.

## Özellikler

- Sonsuz döngü (hayat gibi)
- Rastgele resmi mesajlar
- Gerçek bekleme süreleri (2-5 saniye, çok bilimsel)
- Ctrl+C ile durdurulabilir (ama çay devam eder)
- Kayyum onaylı protokol

## Uyarı

Bu yazılımı çalıştırmak çay içme isteğinizi artırabilir. Sorumluluk kabul edilmez. Her şey kontrol altındadır.
